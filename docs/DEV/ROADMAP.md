# 路线图（ROADMAP）

> 目标与优先级。`P0` 最高。

## 总目标

接手 SimpleFontHook 后，**从「用户实际使用全流程」的体验开始重构优化**，让普通玩家用起来更简单、更少踩坑。

## 阶段规划

### 阶段 0：项目落地（✅ 已完成，2026-10-11）
- 建立独立项目与 Git 版本管理。
- 建立开发日志、决策、交接等管理文档。
- 一键脚本（测试/打包/备份/回退）就位。
- 编译验证通过。

### 阶段 1：梳理现状（进行中）
- **P0 ✅** 通读上游技术文档与 UI 模块文档，画出「用户使用全流程」现状图 → 见 [`USER_FLOW.md`](USER_FLOW.md)。
- **P1 ✅** 列出用户使用中的痛点清单（按严重度排序，P0–P3）→ 见 [`USER_FLOW.md`](USER_FLOW.md) 第 4 节。
- **P1 🔜** 为第一个优化点（建议 P0-1「单击即应用」）建立 `docs/DEV/features/<功能>.md` 档案，并按《两阶段流程》出《变更计划》。

### 阶段 2：体验重构（待开始）

### 阶段 3：稳定与发布（待开始）
- 确定发布节奏、版本号与打包规范（`scripts\2-一键打包.bat`）。
