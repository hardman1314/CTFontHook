# 路线图（ROADMAP）

> 目标与优先级。`P0` 最高。

## 总目标

接手 SimpleFontHook 后，**从「用户实际使用全流程」的体验开始重构优化**，让普通玩家用起来更简单、更少踩坑。

## 阶段规划

### 阶段 0：项目落地（✅ 已完成，2026-10-11）
- 建立独立项目与 Git 版本管理。
- 建立开发日志、决策、交接等管理文档。
- 一键脚本（测试/打包/备份/回退）就位。
- 编译验证通过。

### 阶段 1：梳理现状（进行中）
- **P0** 通读上游技术文档与 UI 模块文档，画出「用户使用全流程」的现状图。
- **P1** 列出用户使用中的痛点清单（按严重度排序）。
- **P1** 为第一个优化点建立 `docs/DEV/features/<功能>.md` 档案。

### 阶段 2：体验重构（待开始）
- 依据痛点清单，逐个优化并可用 `scripts\1-一键测试.bat` 验证。
- 每次改动提交并打标签，便于对比与回退。

### 阶段 3：稳定与发布（待开始）
- 确定发布节奏、版本号与打包规范（`scripts\2-一键打包.bat`）。
- 完善面向用户的使用说明。
