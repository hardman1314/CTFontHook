# 功能档案：安装器浅色主题与图标

> 状态：**已实现，待真机验证观感**　最后更新：2026-10-11

## 1. 设计目标

`CTFontHook-Setup.exe`（安装器）原先是一个朴素的**系统默认外观**窗口（`COLOR_BTNFACE` 灰底 +
原生控件）。本功能把它改成与「字体选择器」**同一套设计语言、但明暗对调**的**浅色主题**窗口，
并接入项目中文名与图标：

- 中文名：**时汐字体器**（窗口标题「时汐字体器 · 安装器」）。
- 图标：窗口图标 + EXE 文件（桌面）图标，取自 `设计图/ico/时汐字体器_*.ico`。
- 与选择器相反的**浅色**主题（选择器是深海蓝暗色）。
- 顺带提升易用性（双击打开目录、行 tooltip、状态着色、键盘导航、按钮悬停）。

**约束**：功能一个不丢——安装 / 卸载 / 清单读写 / PE 检测 / 全部按钮回调逻辑一行不改。

## 2. 设计语言对照（选择器 ↔ 安装器）

| 元素 | 字体选择器（深色） | 安装器（浅色，本功能） |
|------|-------------------|----------------------|
| 窗口底 | `#191f29` | `#f4f6fa` |
| 面板 / 卡片 | `#171e29` | `#ffffff` |
| 描边 | `#2a364a` | `#d5dce6` |
| 主强调 | `#8eb2f4`（亮蓝） | `#3d6fc4`（深蓝，浅底上可读） |
| 警示 | — | `#c4523d`（卸载 / 还原） |
| 主文字 | `#e4e8f0` | `#1f2733` |
| 次文字 | `#8c9db5` | `#5f6b7d` |
| 选中底 | — | `#dce8fa` |

设计语言共同点：圆角卡片、一条**主色顶边**、克制的描边、统一字体 `Microsoft YaHei UI`。

## 3. 实现要点

### 3.1 图标（多尺寸 ICO）

- 源素材 `设计图/ico/` 下是 8 个**单尺寸** `.ico`（各含 1 张 PNG 位图；其中 `_512x512` 实际是 256）。
- 用脚本把 `16/24/32/48/64/128/256` 七个尺寸**按原样拼接**为一个多尺寸 `installer/app.ico`
  （直接搬运条目 + 位图数据、重算偏移，不做重采样，保留手绘小图细节）。
- `installer/resource.h` 定义 `IDI_APPICON 2001`；`installer/version.rc` 里
  `IDI_APPICON ICON "app.ico"` → 既是 EXE 文件图标，也是窗口图标来源。
- `wWinMain` 用 `LoadImage(..., SM_CXICON/SM_CXSMICON)` 加载大小两种，设给 `wc.hIcon/hIconSm`；
  客户区左上角另用 `DrawIconEx` 画一枚 30px 图标作为品牌标识。
- **为何把 ico 复制进仓库**：`设计图/` 未纳入版本控制，直接引用会导致他人/新机器构建缺文件。
- **⚠️ 文件编码**：`installer/resource.h`、`installer/version.rc`、`src/CTFontHook.rc` **必须保存为
  UTF-8 带 BOM**。`rc.exe` 不像 `cl.exe` 那样接受 `/utf-8`，无 BOM 时会按 ANSI/GBK 解析源文件，
  中文注释结尾的字节可能吞掉下一行（详见 §4 与 `DEV_LOG.md` 2026-10-11「图标修复」条）。

### 3.2 浅色主题绘制

- `WM_ERASEBKGND` 返回 1（不擦除）；全部背景在 `WM_PAINT` 里用**内存 DC 双缓冲**绘制：
  窗口底 → 顶部主色强调条 → 应用图标 → 副标题文字 → 列表 / 日志的圆角卡片描边。
- 卡片用「子控件外围画一圈圆角框」实现（`DrawCardAround`）：列表 / 输入框白底与卡片同色，
  只剩 1px 描边可见，视觉上即为圆角卡片。
- `WM_CTLCOLORSTATIC` 统一配色：**只读 EDIT** 走 STATIC 分支 → 白底黑字；其余 STATIC → 透明 + 按控件语义着色
  （提示灰、标签次灰、正文深灰）。`ListView_SetBkColor/TextColor/TextBkColor` 设白底深字。

### 3.3 自绘按钮（`BS_OWNERDRAW`）

- `WM_DRAWITEM` → `DrawOwnerButton`：圆角矩形 + 按控件 ID 区分语义——
  主操作「安装到游戏」用主色、危险操作「卸载 / 还原」用警示色、其余浅色次级按钮。
- 悬停高亮：所有按钮 `SetWindowSubclass` 一项子类过程，维护 `g_btnHot[]` 并 `InvalidateRect` 重绘
  （原生按钮不提供悬停态）。
- 按下态来自 `ODS_SELECTED`，键盘焦点用 `DrawFocusRect`。

### 3.4 易用性

- 列表**双击** = 打开该游戏目录（`NM_DBLCLK`）。
- 列表行**悬停 tooltip** 显示完整路径（`LVS_EX_INFOTIP` + `LVN_GETINFOTIP`）。
- 「状态」列着色：**已安装=绿**、未安装=灰（`NM_CUSTOMDRAW` 子项阶段）；表头浅色底灰字。
- `WS_TABSTOP` + 消息循环 `IsDialogMessage` → **Tab 切焦点、Enter 触发默认按钮**。
- 输入框随窗口拉伸，浏览 / 退出 / 刷新按钮贴右对齐。

## 4. 关键坑 / 注意

- **只读 EDIT 发的是 `WM_CTLCOLORSTATIC`**（不是 `WM_CTLCOLOREDIT`）→ 该分支里必须按类名区分 EDIT 与 STATIC。
- `SetWindowSubclass` 需 comctl32（工程已链接）；子类过程要 `DefSubclassProc` 兜底。
- **rc.exe 的编码陷阱（2026-10-11 修）**：MSBuild 的 `ResourceCompile` 不给 `rc.exe` 传 `/utf-8`，
  而 `rc.exe` 在无 BOM 时按 ANSI/GBK 解析源文件。中文注释的 UTF-8 字节若以「GBK 前导字节」结尾
  （如 `。` = `E3 80 82`），会把紧随的换行吃掉、**连带吞掉下一行代码**——曾因此令
  `#define IDI_APPICON 2001` 失效，图标组名退化成字符串 `"IDI_APPICON"`、窗口/任务栏图标
  变成系统默认图标（EXE 文件图标正常，因为资源管理器走另一条路径）。
  **解法**：RC 参与的文件一律存成 **UTF-8 with BOM**（已实测可行；`/c65001` 亦可，但要改 vcxproj）。
  `version.rc` 的 `ProductName` 仍保持 ASCII 的 `CTFontHook`，**可见中文名靠窗口标题**。
- 全部尺寸走 `S()`（DPI 缩放），避免高分屏错位。

## 5. 验证

- `scripts\1-一键测试.bat` → **4/4 通过**（x64 / Win32 / 安装器 / 导出校验）。
- PowerShell：`[System.Drawing.Icon]::ExtractAssociatedIcon(exe)` 返回 32×32 → 图标已嵌入。
- 图标资源名（2026-10-11 修复后复测）：`pefile` dump 安装器 EXE → **`RT_GROUP_ICON id=2001`**；
  `LoadLibraryExW` + `LoadImage(module, MAKEINTRESOURCE(2001), IMAGE_ICON, sz, sz)` 在 16/32/48
  均返回**有效句柄**（修复前为 0、`err=1813`）。
- **未验证**：浅色主题观感与自绘细节（原生 GDI 窗口，本机无预览）→ 需主人**真机确认**。
