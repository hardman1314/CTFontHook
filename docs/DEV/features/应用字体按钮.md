# 功能档案：应用字体按钮（P0-1）

> 对应痛点：`USER_FLOW.md` 第 4 节 **P0-1「单击只选中、不应用」**。
> 状态：✅ 已实现并通过编译验证（2026-10-11）；同日迭代为「按钮移入选中行 + 当前字体提示」。

## 1. 背景与问题

玩家在字体列表里**单击**一行时，程序只做「选中 + 预览」，并不真正应用；
必须**双击**或按 **Enter** 才生效。小白点一下发现没反应，会以为工具坏了。

原代码：

- 单击仅 `SetSelectedIndex`（`src/ui/internal/input/font_picker_wndproc.cppinc` 的单击分支）。
- 双击才 `ApplySelectedFont()`。
- 预览区右下角只有一行键盘提示 `Enter=应用  Esc=隐藏`。

## 2. 方案取舍

- **方案 A（未采用）**：单击即应用。
  问题：玩家滚列表时每点一下就改字体、每次都写盘 `FontHook.ini`，且难以「先看再决定」。
- **方案 B（采用）**：保持「单击 = 选中」，在预览区右下角新增一个明确的
  **「应用此字体」按钮**，单击按钮才应用。

采用 B：既保留了「先预览再确认」的安全感，又给了一个「看得见、点得着」的明确入口，
不再依赖玩家知道「要双击 / 要按 Enter」。
