# 功能档案：按游戏「打开游戏时默认隐藏窗口」

> 状态：**已实现，4/4 编译通过，待真机验证**　最后更新：2026-10-11

## 1. 需求

- 在字体选择器窗口里放一个勾选框「打开游戏时默认隐藏窗口」。
- 用户勾选后，**只有该游戏**下次启动时默认隐藏选择器窗口；其他游戏照常弹窗。
- 隐藏后可用快捷键呼出。
- 窗口顶部栏给用户「呼出窗口的快捷键」提示。

## 2. 关键结论：天然「按游戏独立」，无需新增存储

- `Config::PickerShowOnStartup`（默认 `true`）**早已存在**，启动时若为 `false` 就隐藏窗口
  —— `ui/internal/font_picker_lifecycle.cppinc:239`。
- `FontHook.ini` 就放在 **DLL 同目录**（`utils.cpp:738` `GetIniPath`），而每个游戏一份 DLL/INI，
  因此该开关**天然只对该游戏生效**，不需要新增字段或改数据结构。
- 热键呼出早已具备：Insert → Pause → Scroll Lock 依次注册
  （`lifecycle.cppinc:103`），`WM_HOTKEY` 已实现呼出/隐藏切换（`wndproc.cppinc:850`）。
- 安全兜底：三个热键都没注册成功时，启动**不隐藏**（P0-2 行为）。

所以本功能的增量只是：**一个勾选框 UI + 一处顶部栏热键提示**。

## 3. 实现要点

### 3.1 勾选框（底栏右侧）

- 位置：底栏右半区，右对齐（替换原先那句语义可疑的「界面预览」，见 §5）。
  矩形由文案实测宽度决定：`state/font_picker_layout_geometry.cppinc` 的 `GetBottomBarHideToggleRect()`。
- 文案常量：`state/font_picker_state.cppinc` 的 `HIDE_ON_STARTUP_LABEL`（`打开游戏时默认隐藏窗口`）。
- 勾选状态**直接读 `!Config::PickerShowOnStartup`**，不新增状态变量；另加一个 hover 变量
  `g_hideOnStartupHovered`。
- 绘制：`paint/font_picker_paint_status.cppinc` `PaintBottomBar`——小方框 + `✓`（勾选时方框填充强调色、
  打勾用面板底色），悬停时文案变亮。为避免与「当前方案：<字体>」重叠，后者右边界收缩到
  勾选框左边界 −8px（`font_picker_paint_status.cppinc`）。
- 交互：`input/font_picker_wndproc.cppinc` 的 `HandleHideOnStartupToggleClick()`——
  切换 `Config::PickerShowOnStartup` 后立即 `SavePickerConfig()` 写入 `FontHook.ini`；
  并在 `WM_MOUSEMOVE` / `WM_MOUSELEAVE` 接入悬停态、在 `WM_LBUTTONDOWN` 链末派发。

### 3.2 顶部栏热键提示

- `paint/font_picker_paint_title.cppinc` `PaintTitleBar`：在「指南」药丸右侧绘制
  `呼出窗口：<热键名>`（热键未注册时显示警示色 `无热键·关闭=最小化`，即把原底栏的 P0-2 提示上移到此）。
- 纯文字、无交互（该区域 `WM_NCHITTEST` 返回 `HTCAPTION`，不拦截点击）。

### 3.3 生效时机

- **下次启动生效**：`lifecycle.cppinc:239` 的判定在进程启动时执行；勾选只是把配置写盘。
- 若该游戏没有可用热键，勾选后仍会照常弹窗（安全兜底），此时顶部栏给出「无热键」警示。

## 4. 明确不改

- `FontHook.ini` 的键名与存储格式（沿用既有的 `PickerShowOnStartup`）。
- 热键注册/协议、注入标记、`winmm.dll` 名与导出表。
- 列表单击只选中 / 预览 A± 不落盘等既有交互。

## 5. 附带发现（只报告）

底栏右侧原先绘制的「界面预览」在代码里像设计文案，但在 Figma 导出 `设计图/CT字体器.json`
里它其实是一个**文本图层名**（`textContent[78]`，`name`/`text` 均为「界面预览」），语义可疑。
本次按批准以勾选框替换该位置；若确认「界面预览」是需要的正式文案，可再调回。

## 6. 验证

- `scripts\1-一键测试.bat` → **4/4 通过**（x64 / Win32 DLL + 安装器 + 双架构导出校验）；
  Win32 `935936 → 588800`。
- 逻辑核对：`Utils::AppendIniText` 即使值为空也会写出键（`utils.cpp:796`），
  `LoadConfig` 因此仍返回 `true`——即「只勾选、未应用字体」的游戏也能正确持久化并生效。
- 坐标估算（默认 `g_uiScale=1.25`、窗口 512）：勾选框内容右对齐止于 `496`、起始约 `351`；
  「当前方案」右边界 `341`，两者不重叠。
