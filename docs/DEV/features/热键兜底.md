# 功能档案：热键兜底——无热键时「隐藏」降级为「最小化」（P0-2）

> 对应痛点：`USER_FLOW.md` 第 4 节 **P0-2「三个热键全被占用时窗口隐藏后无法再打开」**。
> 状态：✅ 已实现并通过编译验证（2026-10-11）。

## 1. 背景与问题

选择器窗口的显隐**只有热键一条路径**：`Insert` → `Pause` → `Scroll Lock`，注册到第一个成功的为止。
若三键全被别的程序占用，则一个都注册不上，程序把热键显示为「未注册」；
此时若玩家点了「关闭」（实为隐藏），窗口就再也叫不回来了 —— **无自救入口**。

## 2. 方案取舍

- **方案 A（采用）**：无可用热键时，把「隐藏」**降级为「最小化」**，并在标题栏用醒目颜色提示
  「无热键·关闭=最小化」。窗口带 `WS_EX_APPWINDOW`，任务栏有按钮，最小化后可重新点开。
- **方案 B（未采用）**：无热键时改为真正「退出」进程。
  问题：退出后本进程的字体替换也随之失效，等于工具失效，反而更糟。
- 其他（未采用）：改右键托盘菜单 / 全局鼠标手势 —— 改动面过大，超出本阶段范围（列为后续可选）。

采用 A：以最小改动提供一个「至少能自救」的兜底，并让玩家从标题栏直接看懂当前状态。
