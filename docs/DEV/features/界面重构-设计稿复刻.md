# 功能档案：界面重构（设计稿复刻）

> 状态：**进行中**（批次 1 / 批次 2 已完成并通过编译验证；批次 3 待做）
> 目标：把 CTFontHook 字体选择窗口按 Figma 设计稿（《CT字体器》/《Main Content》）**严格复刻**为
> 「深海蓝」暗色面板，同时**保留全部既有功能**。

---

## 1. 背景与决策

- **来源**：项目主人在 Figma 中设计了一套专属 CTFontHook 的「字体选择调试器」界面，
  导出数据置于仓库 `设计图/`（`Main Content.json` 为真实窗口稿，`Text.png` 为列表区海报背景图）。
- **三项关键决策（用户确认）**：
  1. **复刻严格度 = 设计外观 + 保留全部功能**：外观严格按设计；但既有功能一个不丢
     （例：字符集药丸保留「韩文」；列表行保留「✓ 已应用 / ☆ 最近」徽章，仅按新配色重绘）。
  2. **窗口尺寸 = 默认 410×724，仍可缩放**（最小 380×660）。
  3. **列表背景图 = 由主人从 Figma 导出**（`设计图/Text.png`，343×412 RGBA）。
- **附加决策**：UI 整体缩放由「标题栏 A−/A+ 按钮」改为 **Ctrl+滚轮**；
  预览字号 A−/A+ **仅本次会话有效**（不写入 ini，默认 22px）。

## 2. 设计规格（从 `设计图/Main Content.json` 提取）

- **窗口**：410×724，圆角 11；底色 `#191f29`。
- **布局纵序**：标题栏 32 / 搜索 27 / 字符集药丸 38 / 列表(约 205) / 提示行 24 /
  兼容设置(伪装 40 + 映射转码 34 + 字形微调 150) / 文字预览 136 / 底栏 29。
  各区块自下而上定位，**底栏始终贴底**。
- **配色**：标题栏渐变 `#252e40→#222c39`；搜索框 `#121821`；选中行渐变
  `#283750→#253248→#202b3d` + 描边 `#608cdb` + 左侧竖条 `#8cb7ff→#74c4c9`；
  普通行 `#1b2433` alpha 0.47→0.11；设置区渐变 `#1c2430→#19222d`；
  预览框 `#243449→#1b2c3b` + 辉光 `#467489`；主文字 `#e4e8f0`，次文字 `#8c9db5`，
  状态点 `#64c7a5`，强调色 `#8eb2f4`。
- **字体**：界面统一 `Microsoft YaHei`；标题 11px、提示 8px、设置标题 10px、
  字形标签/按钮 9px、预览文字 22px。

## 4. 已知限制 / 风险

- GDI 无法完全复刻 Figma 的**斜向渐变**与亚像素值 → 统一用整数近似。
- 窗口圆角目前为「1px 圆角描边贴合方角窗口」（无原生边框）；后续如需真圆角需改用 Region。
- **无法在本机做可视化验证**（原生 GDI 窗口，无浏览器/开发服务器）→ 观感确认依赖主人**真机验证**。
