# 功能档案：选择器窗口优化（图标 / 标题 / 面积 / 页脚 / 缩放控件 / 整体缩放 / 定位）

> 状态：**已实现，4/4 编译通过，待真机验证观感**　最后更新：2026-10-11

## 1. 设计目标

主人真机使用字体选择器后提出的 7 条体验问题，一次性修复：

1. **窗口/任务栏图标未更新** —— 选择器沿用旧图标，应与安装器一致用 `设计图/ico` 那一套。
2. **顶部「指南」药丸与标题文字重合** —— 药丸左边界压到了标题。
3. **列表区偏高、预览区偏矮** —— 压缩列表区、放大预览展示区。
4. **预览框底部信息与样例文字重叠** —— 把「游戏/选择/序号」信息迁到页脚「点击文字编辑预览」右侧。
5. **预览标题右侧 A− / 数值 / A+ 控件显示异常** —— 三者在旧坐标下互相重叠、文字被裁。
6. **拖拽缩放只拉大窗口边框** —— 期望拖拽=整窗内容等比缩放（而非只改外框、内容不动）。
7. **底栏「当前方案：<字体>」不可点** —— 期望点击后自动定位/滚动到该字体所在行。

## 2. 实现要点（按项）

### 项 1　窗口图标（`.rc` + 生命周期）

- 新增 `src/res/app.ico`（复制自 `installer/app.ico`，7 尺寸多帧 ICO）。
- `src/CTFontHook.rc` 追加 `2001 ICON "res\\app.ico"`；资源 ID 与
  `src/ui/internal/state/font_picker_state.cppinc:456` 的 `APP_ICON_RESOURCE_ID` 一致。
- `src/ui/internal/font_picker_lifecycle.cppinc`：
  - 注册窗口类时 `wc.hIcon` / `wc.hIconSm` 从资源载入（`:9` / `:12`）。
  - 窗口创建后补发 `WM_SETICON`（`ICON_BIG` / `ICON_SMALL`，`:49` / `:53`），确保任务栏图标生效。

### 项 2　「指南」药丸与标题重合

- `font_picker_layout_geometry.cppinc:34`：`GetHeaderPillRect()` 由固定像素改 `SF()` 缩放并右移，
  药丸左边界 `SF(108)`，标题文字止于 `SF(100)` → 留约 10px 间隙，不再重叠。

### 项 3　列表区减小、预览区增大

- `font_picker_state.cppinc:182`：`PREVIEW_HEIGHT 136 → 164`（+28）。列表区 = 窗口高减去全部定高区，
  预览区变高 28px 后，列表区自动等量变小，无需另改列表逻辑。

### 项 4　预览底部信息迁到页脚行右侧

- `paint/font_picker_paint_preview.cppinc`：删除预览框左下角的「检测/选择」信息块；改为在页脚行
  「点击文字编辑预览」右侧 **动态取剩余宽度** 绘制
  `游戏: <名> (<码>) | 选择: <名> (<码>) | n/N`（`:109`–`:135`）。
  右侧并**预留**了「当前字体：<名> ⌄」提示实际文字宽度，避免两者相撞（`:129` / `:130`）。

### 项 5　A− / 数值 / A+ 控件显示异常

- `font_picker_layout_geometry.cppinc:117`–`:123`：三个矩形改 `SF()` 缩放并重新分配水平位置与宽度，
  Minus/Value/Plus 不再重叠、数值不再被裁。

### 项 6　拖拽缩放 = 整窗等比缩放（reduced model）

- 尺寸约束：`font_picker_state.cppinc:227` / `:228` 定义设计基准 `410×724` 与最小 `340×600`。
- `WM_SIZING`（`input/font_picker_wndproc.cppinc:870`）：拖拽时锁定 **410:724 宽高比**
  （左右边→按宽推高，上下边→按高推宽），窗口只能等比变化。
- `WM_SIZE`（`:900`）：客户区宽反推 `g_uiScale = WINDOW_WIDTH / 410`（夹取 0.7–1.8）。
- `SizeWindowForUiScale()`（`:309`）：Ctrl+滚轮改缩放后按新比例 `SetWindowPos` 同步窗口大小。
- 创建窗口时（`lifecycle:22`–`:33`）：按整屏可用区夹取一个不超屏的 `s`，算出初始 `WINDOW_WIDTH/HEIGHT`。
- **缩放语义（重要，reduced model）**：文本/控件/行高等 `SF()` 内容随 `g_uiScale` 缩放；
  各「区高常量」（标题 32 / 搜索 27 / 药丸 38 / 提示 24 / 预览 164 / 底栏 29 等）仍是**设计稿原始像素**，
  列表区吸收剩余高度。默认窗口约 `512×905`，列表可见 **5 行**不变。
  （曾评估「全量等比」会让列表从 5 行掉到约 3 行，与主人「稍微减小列表」的诉求相悖，故未采用。）

### 项 7　底栏「当前方案」可点击定位

- `font_picker_state.cppinc:320`：新增悬停态 `g_bottomAppliedHovered`。
- `font_picker_layout_geometry.cppinc:83`：`GetBottomBarAppliedRect()` 取底栏左半区为热区。
- `input/font_picker_wndproc.cppinc:141`：`HandleBottomAppliedClick()` → 调 `FocusAppliedFontInList()`
  （`input/font_picker_selection.cppinc:10`）滚动并选中该字体，然后刷新列表/滚动条/预览/底栏。
- 悬停时文字变强调色（`paint/font_picker_paint_status.cppinc:48`），给出可点提示。

## 3. 明确不改

- 列表单击仍只选中、双击/Enter 才应用（P0-1 的既定交互，未动）。
- 预览字号 A−/A+ **仅本次会话有效、不落盘**（沿用批次 1 约定）。
- 各功能的数据流、配置键、注入/热键协议、`winmm.dll` 名与导出表：零改动。

## 5. 待办 / 已知限制

- **真机验证**：本机为无 GUI 的构建环境，**无法可视化验证**上述观感，需主人在真机确认：
  图标是否更换、药丸/标题间距、列表与预览比例、页脚信息排布、A± 控件、拖拽缩放手感、底栏定位点击。
- 缩放为「reduced model」：定高区不随缩放变化，缩放比例过大时列表行数会随之增减（属预期）。
- 相关常量集中在 `font_picker_state.cppinc` 顶部，观感需微调时改这里即可。
